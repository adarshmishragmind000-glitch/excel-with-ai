INTERNSHIP CURRICULUM

What You Will Actually Do in 6 Weeks

A structured, beginner-friendly plan: learn a concept, practise it, submit your work and build towards a final project. You select one technical track at application.

06Weeks of guided learning
12Core practical assignments*
01Track-based final project
01Final assessment & demo

*The plan is designed around two practical assignments per week. Exact task sheets and submission dates will be shared after onboarding. The selected track determines the practical work.

WEEK 01

Orientation & Foundations

Understand the internship workflow, tools, professional conduct and the basics of your selected track.

  • Set up required software and workspace
  • Learn the core concepts and terminology
  • Practical 01: environment setup / tool familiarisation
  • Practical 02: beginner-level guided task
Weekly output: Setup checklist + first submission
WEEK 02

Core Skills & Guided Practice

Move from watching examples to completing small tasks independently.

  • Learn the main tools and workflow
  • Practise a real-world use case
  • Practical 03: skill-building exercise
  • Practical 04: task with your own solution
Weekly output: Two completed practical files
WEEK 03

Applied Skills

Combine concepts and solve a slightly larger problem using your track tools.

  • Work with structured inputs and outputs
  • Debug, verify or improve your work
  • Practical 05: intermediate task
  • Practical 06: mini case study
Weekly output: Mini case study / working exercise
WEEK 04

Build a Working Solution

Start planning and developing the final project with smaller milestones.

  • Define a problem and project objective
  • Create the first working version
  • Practical 07: project component one
  • Practical 08: project component two
Weekly output: Project proposal + first build
WEEK 05

Project Development & Testing

Complete the main project, test it and improve it using feedback.

  • Develop remaining project features
  • Test, find errors and make corrections
  • Practical 09: testing / validation task
  • Practical 10: improvement task
Weekly output: Near-final project + test notes
WEEK 06

Final Submission & Assessment

Present your work and demonstrate what you can do—not just what you have watched.

  • Finish and organise project files
  • Practical 11: documentation / report
  • Practical 12: final demonstration preparation
  • Submit project and attend assessment
Weekly output: Final project + assessment
TRACK-WISE PRACTICALS

Choose Your Track. Build Your Own Project.

These are sample practical activities and project directions for each track. Your application is for one selected track, so you focus on that skill area instead of studying all six tracks at once.

01 / WEB

Web Development

Tools: VS Code, browser, HTML, CSS, JavaScript, Git/GitHub basics.

  1. Create a structured multi-section webpage using HTML.
  2. Style a responsive page with CSS layout and typography.
  3. Build forms, navigation and interactive components.
  4. Use JavaScript for validation and simple dynamic behaviour.
  5. Publish code to a GitHub repository and test on mobile.
Final project idea
Responsive business / portfolio website with a working contact form interface.
02 / PYTHON

Python Programming

Tools: Python 3, VS Code or IDLE, CSV files.

  1. Write programs using variables, input and output.
  2. Practise conditions, loops and functions.
  3. Work with lists, dictionaries and string operations.
  4. Read and write files; handle common errors.
  5. Break a problem into functions and test the solution.
Final project idea
Student record or expense tracker using Python and file storage.
03 / DATA

Data Analytics & Excel AI

Tools: Microsoft Excel / compatible spreadsheet tools, sample datasets, AI assistant.

  1. Clean and organise a raw data sheet.
  2. Use formulas, IF, SUMIF, COUNTIF and lookup concepts.
  3. Create PivotTables, charts and summary reports.
  4. Use AI prompts to explain data and assist formula creation; verify outputs.
  5. Build a dashboard with key metrics and filters.
Final project idea
Sales / attendance analytics dashboard with insights and a short report.
04 / SECURITY

Cyber Security

Tools: Browser security tools, Linux basics and safe practice labs.

  1. Learn CIA triad, threats, vulnerabilities and safe lab rules.
  2. Practise password hygiene and multi-factor authentication review.
  3. Inspect basic network concepts and sample traffic in a lab.
  4. Identify common web security risks using intentionally vulnerable labs.
  5. Prepare a risk checklist and defensive recommendations.
Final project idea
Cyber safety audit report for a sample website or small organisation. All testing stays within authorised labs.
05 / AI

Artificial Intelligence

Tools: AI assistant, Python notebook/environment where applicable, sample data.

  1. Understand AI, machine learning and generative AI basics.
  2. Write and improve prompts for specific tasks.
  3. Compare AI outputs and check accuracy and limitations.
  4. Work through a beginner data / prediction demonstration.
  5. Design a small AI-assisted workflow with human review.
Final project idea
AI study helper, FAQ assistant prototype or documented AI workflow.
06 / BACKEND

Database & Backend Basics

Tools: SQL database environment, API testing tool and code editor.

  1. Understand tables, records, keys and relationships.
  2. Create tables and practise INSERT, SELECT, UPDATE and DELETE.
  3. Use WHERE, ORDER BY, JOIN and aggregate queries.
  4. Understand backend routes, request/response and REST API basics.
  5. Test sample API endpoints and connect a simple data flow.
Final project idea
Basic student/course record system design with database schema and API demonstration.
Important: Project examples are learning projects, not promises of production deployment, employment or client work. Cyber Security activities are restricted to authorised training environments. AI-generated results must be checked by the student.
HOW YOUR WORK IS EVALUATED

Completion Is Based on Your Work

Watching lessons alone is not completion. Students must submit practical work and demonstrate their understanding.

01 · Practical submissions

Completion, correctness and effort in the weekly tasks.

02 · Project quality

Whether the final project works as described and matches the selected track.

03 · Documentation

Clear project files, explanation and basic record of the work completed.

04 · Final assessment

Short demonstration, questions and explanation of your own contribution.

Certificate policy: A certificate is not automatic. It may be issued only after the student completes the required activities, submits the final project and passes the assessment. No job, placement or guaranteed certificate is promised.
