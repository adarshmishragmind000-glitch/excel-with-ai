What you will learn and use

Tools & working environment

SQLite or another training SQL environment, code editor, sample datasets and an API testing tool such as Postman or an equivalent.

How the learning works

  • Learn the concept through guided instruction and examples.
  • Complete two practical assignments each week.
  • Submit your work for review and improve it using feedback.
  • Keep your project files and notes organised as a portfolio.

What you should have by the end

  • Track-specific practical files and task submissions.
  • One completed final project with documentation.
  • Evidence of your work such as screenshots, code, workbook or report.
  • Experience explaining your approach in a project demonstration.
  • A clearer view of the next skills to learn for entry-level roles.
WEEK-BY-WEEK PLAN

Your complete 6-week roadmap

Each week includes two practical assignments. Exact task sheets, submission dates, mentor review schedule and delivery mode will be shared during onboarding.

WEEK 01Database concepts

Week 1 — Database concepts

What you will learn

  • Understand database, DBMS, tables, rows, columns, primary and foreign keys.
  • Design a simple student/course data model.

Practical assignments

  • Draw an ER diagram for a small institute.
  • Create tables with suitable fields and keys in a practice database.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

WEEK 02SQL CRUD

Week 2 — SQL CRUD

What you will learn

  • Practise CREATE, INSERT, SELECT, UPDATE and DELETE.
  • Use WHERE, ORDER BY, LIMIT and basic aggregate functions.

Practical assignments

  • Insert and manage sample student records.
  • Write 12 SQL queries for search, sorting and summary tasks.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

WEEK 03Relationships and joins

Week 3 — Relationships and joins

What you will learn

  • Understand one-to-one, one-to-many and many-to-many relationships.
  • Practise JOIN, GROUP BY and HAVING on sample data.

Practical assignments

  • Connect students, courses and enrolments in sample tables.
  • Create a report query using JOIN and GROUP BY.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

WEEK 04Backend and APIs

Week 4 — Backend and APIs

What you will learn

  • Understand client/server, HTTP methods, status codes and JSON.
  • Explore REST API request/response using a safe sample API.

Practical assignments

  • Map CRUD actions to GET, POST, PUT/PATCH and DELETE.
  • Test sample endpoints and document request/response fields.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

WEEK 05Mini system design

Week 5 — Mini system design

What you will learn

  • Plan a small student/course record workflow.
  • Connect the data model to a simple backend demonstration or documented API flow.

Practical assignments

  • Create a schema and sample data for the mini project.
  • Demonstrate or document create/list/update operations in a training environment.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

WEEK 06Final submission

Week 6 — Final submission

What you will learn

  • Prepare SQL script, ER diagram, API notes and test cases.
  • Explain database design choices and basic data safety.

Practical assignments

  • Submit database file/script, query set and project documentation.
  • Demonstrate queries/API flow and complete assessment questions.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

CAPSTONE • FINAL SUBMISSION

Your final project

A Student/Course Record System prototype with an ER diagram, relational tables, SQL CRUD queries and a documented or demonstrated API workflow.

Final deliverables: Project files, screenshots/demo evidence, short documentation or README, and an individual presentation/viva-style assessment.

CAREER PATHWAYS

What jobs can this skill lead towards?

This internship helps you build beginner-level exposure and a project to discuss in interviews. Job titles below are possible career directions—not a promise that this short internship alone qualifies you for each role.

Possible entry-level roles

  • SQL / Database Intern
  • Backend Developer Trainee (with a programming framework)
  • Database Support Assistant
  • Application Support / Technical Support Trainee

Where to explore opportunities

Explore software product companies, IT service firms, ERP vendors, SaaS startups and organisations with database/application support teams. Backend developer jobs typically require additional language/framework practice.

What to learn next

  • Choose a backend language: Python, JavaScript/Node.js, Java or PHP
  • Build REST APIs and authentication securely
  • Practise database indexing, backups and deployment basics

Job & internship alerts

Relevant SQL, database support, backend trainee and application-support openings may be shared when verified and available. Employers set their own eligibility and selection criteria.

Important: Sharing an opportunity is not a referral, interview call or placement guarantee. Always apply through the employer's official channel and verify the listing.

ASSESSMENT & CERTIFICATE

How completion is evaluated

Assessment components

  • Practical task completion and quality.
  • Final project functionality, relevance and originality.
  • Documentation and submission discipline.
  • Ability to explain your work and answer questions.

Certificate eligibility

Certificate is assessment-based. Students who complete the required activities, submit the final project and pass the assessment may qualify, subject to the programme's final review. Application or attendance alone does not guarantee a certificate.

Career transparency: This is a learning internship, not a guaranteed placement programme. Employer names mentioned as examples are not claimed as partners. Job openings change frequently and students are responsible for checking current requirements.
