WEEK-BY-WEEK PLAN

Your complete 6-week roadmap

Each week includes two practical assignments. Exact task sheets, submission dates, mentor review schedule and delivery mode will be shared during onboarding.

WEEK 01Python setup and fundamentals

Week 1 — Python setup and fundamentals

What you will learn

  • Install/check Python and run your first script.
  • Practise variables, data types, input, output and operators.

Practical assignments

  • Create a marks/grade calculator.
  • Submit 10 small logic exercises with sample outputs.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

WEEK 02Decisions and loops

Week 2 — Decisions and loops

What you will learn

  • Use if/elif/else and comparison/logical operators.
  • Practise for/while loops, range and nested repetition.

Practical assignments

  • Build a menu-driven calculator.
  • Create number guessing or quiz program with score.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

WEEK 03Data structures and functions

Week 3 — Data structures and functions

What you will learn

  • Work with strings, lists, tuples and dictionaries.
  • Create reusable functions and validate user input.

Practical assignments

  • Build a contact list or inventory tracker in memory.
  • Split a program into functions and test invalid inputs.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

WEEK 04Files and error handling

Week 4 — Files and error handling

What you will learn

  • Read/write text and CSV files.
  • Use try/except and organise code into modules.

Practical assignments

  • Save and load student records from CSV.
  • Add search, update and delete operations.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

WEEK 05Application development

Week 5 — Application development

What you will learn

  • Plan the user flow and data fields for your project.
  • Combine functions, collections and file storage into one application.

Practical assignments

  • Build the main working version of a student/expense tracker.
  • Test normal, missing and incorrect input cases.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

WEEK 06Testing and presentation

Week 6 — Testing and presentation

What you will learn

  • Prepare sample data, usage instructions and code comments.
  • Explain logic, functions, file handling and limitations.

Practical assignments

  • Submit source code, sample CSV, README and screenshots.
  • Demonstrate the application and complete assessment questions.

Weekly submission: Complete both practical tasks and submit files/screenshots/notes as instructed.

CAPSTONE • FINAL SUBMISSION

Your final project

A menu-driven Student Record or Expense Tracker using Python functions and CSV file storage, with add/search/update/delete features.

Final deliverables: Project files, screenshots/demo evidence, short documentation or README, and an individual presentation/viva-style assessment.

ASSESSMENT & CERTIFICATE

How completion is evaluated

Assessment components

  • Practical task completion and quality.
  • Final project functionality, relevance and originality.
  • Documentation and submission discipline.
  • Ability to explain your work and answer questions.

Certificate eligibility

Certificate is assessment-based. Students who complete the required activities, submit the final project and pass the assessment may qualify, subject to the programme's final review. Application or attendance alone does not guarantee a certificate.

Career transparency: This is a learning internship, not a guaranteed placement programme. Employer names mentioned as examples are not claimed as partners. Job openings change frequently and students are responsible for checking current requirements.
